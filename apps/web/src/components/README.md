# Components (shared/reusable UI)

Small, route-scoped, reusable pieces (e.g. `ProductCard`, `ImageGallery`, `SellerCard`, `LoadingState`, `EmptyState`, `Navbar`, `Footer`).

Convention (CLAUDE.md §7): keep components small; do **not** build a giant component library upfront. Extract to here only once a piece is used in more than one place.
